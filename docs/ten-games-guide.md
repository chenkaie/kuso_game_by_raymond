## 使用與執行說明

1. **直接遊玩**：解壓縮後，雙擊任意 `.html` 檔案即可在 Chrome、Safari、Edge 等現代瀏覽器中直接開啟遊玩（所有 HTML、CSS 與 JavaScript 邏輯皆已內嵌整合於單一檔案中）。
2. **網路需求**：各遊戲使用 Tailwind CSS CDN 與 Three.js CDN（3D 遊戲），開啟時請保持網路連線以正常載入樣式與 3D 引擎。
