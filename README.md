## 什麼是糞 Game？

「糞 Game」（Kuso Game）源自日語「クソゲー」，原指品質不佳、令人失望的遊戲。有些玩家反而會從荒謬的設計與意外的缺陷中找到樂趣；Kuso 在華人文化中也逐漸帶有惡搞的意思。這裡以幽默、自嘲的方式命名，收藏雷門充滿創意與實驗精神的遊戲作品，並非否定作品的價值。

參考：[維基百科｜劣質遊戲](https://zh.wikipedia.org/zh-tw/%E5%8A%A3%E8%B3%AA%E9%81%8A%E6%88%B2)。

## 長期維護原則

最終建議是將所有遊戲完整移植至 GitHub，讓每款遊戲都能獨立運作，不再依賴 ChatGPT Sites。這樣未來就能透過 Git 進行版本管理、功能更新及長期維護。

有新的遊戲版本時，優先取回實際原始碼、確認能獨立運作、更新同一個遊戲目錄及首頁，不另建重複的舊版入口。
