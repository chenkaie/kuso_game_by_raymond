# 《三國無雙：群雄逐鹿》遊戲說明文件

## 1. 遊戲簡介
《三國無雙：群雄逐鹿》是一款融合無雙割草動作與即時領兵陣型調度的單機網頁動作策略遊戲。採用單一 HTML5 檔案封裝，免安裝、免伺服器，支援電腦鍵盤與平板（iPad / Android 平板）全觸控雙重操作。

---

## 2. 核心特色
1. **六大三國傳奇名將（雙將無縫切換系統）**：
   - **關羽**（武聖・青龍偃月）：高血量重擊，無雙技「青龍偃月斬」大範圍橫掃。
   - **趙雲**（常勝・龍膽亮銀）：高機動連刺，無雙技「七進七出龍捲」高速清場。
   - **諸葛亮**（臥龍・八陣神算）：遠程三向扇氣波，無雙技「八陣天雷轟」全屏落雷。
   - **呂布**（飛將・方天畫戟）：全場最高武力，無雙技「鬼神天下無雙」毀滅衝擊波。
   - **張飛**（猛將・丈八蛇矛）：霸體重矛橫掃，無雙技「當陽橋怒吼」震退周圍敵軍。
   - **孫尚香**（梟姬・日月神弓）：高速穿透連射，無雙技「梟姬萬箭齊發」漫天箭雨。
   - 戰前可在點將台指定 **主將** 與 **副將**，戰鬥中隨時可一鍵無縫切換（切換瞬間附帶無敵護盾與範圍衝擊特效，待命副將亦會自動緩慢回復體力）。
2. **六大精銳兵種與四種即時軍陣**：
   - 收錄 **長槍兵、連弩手、西涼鐵騎、藤甲盾衛、烈火軍師、虎豹刺客** 六種兵種協同作戰。
   - 支援 **🛡️ 護衛、🔺 鋒矢、⭕ 圓陣、💥 突擊** 四種即時陣型切換與「➕ 徵兵」增援。
3. **五大經典戰役關卡**：
   - 依序挑戰 **黃巾之亂（張角）**、**虎牢關前哨（華雄）**、**官渡奇襲戰（顏良）**、**赤壁火攻陣（曹仁）** 與 **五丈原決戰（司馬懿）**。

## 3. 操作方式

### 📱 平板 / 手機觸控操作
- **點將台選將**：直接點擊武將卡片即可指派主將／副將，或點擊「🎲 隨機雙將」，確認後點擊「⚔️ 開始征戰」。
- **移動**：使用畫面左下角虛擬方向鍵（⬆️ ⬇️ ⬅️ ➡️）。
- **普通攻擊**：點擊右下角紅色圓形大按鈕「⚔️ 斬擊」。
- **主／副將切換**：點擊右下角藍色按鈕「🔄 換將」。
- **施放無雙技**：無雙值集滿 100% 時，點擊右下角金紅色按鈕「🔥 無雙技」。
- **軍陣切換與徵兵**：點擊畫面右上角陣型按鈕（護衛／鋒矢／圓陣／突擊）與「➕ 徵兵」。

### 💻 電腦鍵盤操作
- **移動**：`W` / `A` / `S` / `D` 或 方向鍵
- **普通攻擊**：`Space`（空白鍵）或滑鼠點擊「⚔️ 斬擊」
- **主／副將切換**：`Q` 鍵或滑鼠點擊「🔄 換將」
- **施放無雙技**：`E` 鍵或滑鼠點擊「🔥 無雙技」
